================================================================
  AR の公開・スマホでの試し方（簡易版）
================================================================

■ スマホですぐ試す（Windows）
────────────────────────────────
  1. 「ARをスマホで試す（ngrok）.bat」をダブルクリック
  2. 表示された https://... の URL をスマホで開く
  3. カメラを許可 → マーカー画像を映す

  ※ 初回は ARtrium Editor の「初回セットアップ（ngrok）.bat」が必要


■ GitHub Pages で公開（無料・URL固定）
────────────────────────────────
  1. github.com で無料アカウント作成
  2. New repository で新規リポジトリ作成（Public）
  3. このフォルダの中身をすべて Upload
  4. Settings → Pages → Branch: main / root → Save
  5. 1〜2分後、表示された URL をスマホで開く
     例: https://ユーザー名.github.io/リポジトリ名/


■ 注意
────────────────────────────────
  ・AR には HTTPS が必要です（ngrok / GitHub Pages は OK）
  ・index.html を直接ダブルクリックでは動きません
