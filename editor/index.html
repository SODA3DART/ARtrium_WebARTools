ARtrium WebAR Editor

3Dモデル（GLB）と MindAR データをアップロードするだけで、 「飛び出す AR」の Web ページ一式が ZIP でダウンロードできます。 Three.js プレビューでレイアウト調整も可能。プログラミング不要です。

1 マーカー画像をアップロード

カメラで認識させる画像です。ポスター・イラスト・ロゴなど、 はっきりした模様がある画像を使ってください。

🖼️
クリックまたはドラッグ＆ドロップ
PNG / JPG / WebP

2 MindAR ターゲット（.mind）をアップロード

上のマーカー画像から生成した .mind ファイルです。 まだお持ちでない場合は、下の手順で無料で作れます。

MindAR ターゲットの作り方（約1分）
  1. 下のボタンから MindAR Compiler を開く
  2. Step 1 で用意した同じ画像をアップロード
  3. 「Compile」をクリックして .mind をダウンロード
  4. ダウンロードしたファイルをここにアップロード
MindAR Compiler を開く →
🎯
.mind ファイルをアップロード
MindAR Compiler で生成したファイル

3 3D モデル（GLB）をアップロード

マーカーの上に表示される 3D キャラクターやオブジェクトです。 Blender などから GLB 形式で書き出したファイルを使います。

🧊
GLB ファイルをアップロード
メインの 3D モデル（必須）

任意 ステージ（背景）モデルや BGM も追加できます

🏟️
ステージ GLB（任意）
キャラの下に敷くモデル
🎵
BGM（任意）

4 3D レイアウトを調整

Three.js プレビュー上でモデルの位置・回転・大きさを調整できます。 マーカー（白い板）から飛び出すように見えるよう配置してください。

💡 ギズモをドラッグするか、下の X / Y / Z の数値を変更して調整できます（入力するとすぐ 3D に反映されます）。

5 表示設定

わからない場合はそのままで OK です。あとから ZIP 内の設定ファイルで変更もできます。

ZIP には index.html・設定ファイル・3D モデル・マーカーがすべて含まれます。
解凍後、Web サーバーに置けばすぐ AR 体験として公開できます。
